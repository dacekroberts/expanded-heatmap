# Data sources — Netherlands

Part of [`data_sources.md`](../data_sources.md), the project's provenance
record, which was split by country on 2026-09-27. This file holds the
Netherlands rows of the tables there and the source sections about its cities,
moved verbatim under the same headings. The numbered notices this project must
display, the removal-request commitment and the deploy gate are in the entry
point, not here.

Tram 3 is on GVB's map and runs no trip in the window - not drawn. **Tram colours are GVB's own**, read from `GVB_railnetwerk_31aug_2026.pdf` (linked from gvb.nl/plattegronden) as each line badge's fill - the feed carries none and OSM's are unusable; metro colours are the feed's `route_color`; five trams lightened or darkened in HSL lightness to clear the colour check (GVB gives 6 and 25 one red, 19 and 29 one orange). Licence **CC0** - **nothing to display**; MUST NOT say or imply the site represents GVB (README), no GVB marks (CC0 §4) |
