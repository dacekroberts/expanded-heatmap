# Handoffs

Start prompts and session-to-session notes, kept as history. Each one was
written for a session that has since finished; none is an open task. Open work
is in `PLAN.md`.

These files lived in `docs/` until 2026-10-16. Entries in `DECISIONS.md`,
`docs/decisions/` and `docs/plan_done/` are append-only, so they still give the
old path: read `docs/handoff_<name>.md` there as `docs/handoffs/handoff_<name>.md`.
Live documents were repointed when the files moved.
