# Communications

Every letter this project has sent, owes or has drafted to a publisher or
agency, one file each, and the batch check-in that keeps them honest (owner,
2026-10-04: "file into a communications folder and we can do batch check ins
about all required communications"). Formerly `docs/notifications/`.

Only the owner sends anything, from the owner's own address. **Silence is not
consent**: no page, doc or decision may treat an unanswered request as
permission, and an interim position rests on its own reasoning and disclosure,
never on the absence of a reply. Many of these will stall indefinitely; that
is expected, and a stalled request changes nothing on the site.

## The batch check-in

At a check-in, the owner looks at every SENT row's inbox and says what came
back; Cleanup updates the row, the file's status line, and any position that
rested on it. Nothing is chased between check-ins. A DRAFTED row is listed so
it is not forgotten, not as a reminder to send.
