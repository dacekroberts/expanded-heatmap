CAPTURE NOTE: rendered-text capture, not raw HTML. Surrey's portal is an
ArcGIS Hub site (data.surrey.ca redirects to opendata-surrey.hub.arcgis.com)
and every page is JavaScript-rendered, so the page was read in the browser
pane and its text copied unaltered. Re-verify against the live page rather
than trusting this file alone if a clause is ever load-bearing.

NOTE ON SCOPE: this covers Surrey's own data, including the Business
Directory. It does NOT cover the rail that makes Surrey reachable - SkyTrain
is TransLink's, under `translink-open-api-terms-of-use.txt`, which is far
tighter and still unresolved for static GTFS.
