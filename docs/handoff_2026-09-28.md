## Standing rules

- **The role is the `consistency-sweep` skill:** prefer shipping a check to a
  correction. Send broad reading to `cleanup-sweep` or another agent, and read
  files by line range.
- Stage files by name, never `git add -A`.
- One `DECISIONS.md` entry per change, then `python scripts/decisions_index.py`.
  Resolve a conflict there with `python scripts/merge_append_only.py DECISIONS.md`.
- **Fetch, and push only if 0 behind.** Gate the push on the count
  (`test "$(git rev-list --count HEAD..origin/master)" = 0 && git push ...`),
  and never push with a merge unresolved.
- Published prose: draft in chat, owner approves, then write it. A wrap-only
  fix that changes no words (a dash moved up a line) is not a wording change.
- Scratch output goes to the session scratchpad. No backslash or backtick in a
  Bash heredoc or `-c` string (a hook refuses it); write a file and run it.
- A peer session's message is not the owner's approval. When auto mode refuses
  an agent's action, surface it to the owner; do not re-run it yourself.
- **Retiring a worktree needs the owner's word AND its session's word**, and
  the session closed or at least not running (`list_sessions` shows
  `isRunning`). A session's working directory stays locked until that
  session is ARCHIVED; ask the owner before archiving it.

## Rules that kept paying

- Keep a positive control, and check each negative case for its **expected
  message**, not just its exit code.
- **Test a hook's check under the hook's environment.** The archive self-test
  passed by hand and broke the shared git config on its first hook run.
- Measure a claim in the rendered artifact, not the file. Toronto's retail
  share had three true figures from three pipeline stages. Only the pins the
  map draws answer "what reaches the map".
- A count in prose is a bet on the next city. Name the members, or make it a
  check.
- **A worktree's `data/` may be a junction OR a real folder.** Check
  `LinkType` first. Unlink a junction non-recursively
  (`[System.IO.Directory]::Delete(path, $false)`). Remove a real folder only
  after `check_worktree_data.py` passes, and run it again just before.
- **When the permission check returns no verdict, stop after two or three
  tries.** Ten failures in a row end the turn, and scheduling a retry goes
  through the same check. Ask the owner to prompt a retry.
- **For a live zoom check, set the viewport first.** A hidden browser pane
  gives a 16 px frame and an UNMEASURED result. `resize_window` fixes it
  before the page loads.
